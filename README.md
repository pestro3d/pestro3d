# Pestro3D

A premium Next.js storefront for custom 3D miniature keepsakes and gifting experiences.

## Overview

This repository contains a storefront concept for turning customer photos into a hand-painted miniature figurine. The experience includes:

- premium warm editorial landing page
- custom product flow and order concept
- Supabase-ready configuration
- environment variable template for local development

## Tech stack

- Next.js + TypeScript
- Tailwind CSS
- Supabase client integration
- Vercel-ready app structure

## Local development

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Environment

Copy `.env.example` to `.env.local` and fill in your Supabase values before running the app.

## Build verification

```bash
npm run build
npm run lint
```
